# Salary & Attendance Manager

বাংলা Android app project — বেতন হিসাব, দৈনিক মজুরি, হাজিরা, OT হিসাব, calculator এবং custom daily reminder notification।

## Android Studio
1. ZIP extract করুন।
2. Android Studio → File → Open → `SalaryAttendanceManager` folder নির্বাচন করুন।
3. Gradle sync শেষ হলে Run চাপুন।
4. APK বানাতে: Build → Build APK(s)।

## ফিচার
- মাসিক বেতন ও প্রতি দিনের মজুরি
- উপস্থিত/অনুপস্থিত দিন
- OT ঘণ্টা × প্রতি ঘণ্টা OT রেট = মোট OT
- সাধারণ calculator (+, -, ×, ÷)
- কাস্টম reminder text ও সময়
- প্রতিদিন নির্ধারিত সময়ে notification
- বাংলা UI

> Android 13+ এ notification permission চাইবে। Reminder চালু করতে সেটি Allow করতে হবে।
